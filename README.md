# PM 주차 판정 실험 (웹)

휴대폰을 킥보드 데크 위에 올려두면 GPS와 가속도·자이로로 주차 상태를 판정하는 실험 도구입니다.
빌드 단계 없는 정적 사이트라서 GitHub Pages에 그대로 올리면 휴대폰에서 링크로 열 수 있습니다.

판정 결과는 세 가지입니다.

| 결과 | 조건 |
|---|---|
| 사진 없이 반납 | 모든 항목 통과 |
| 사진으로 확인 | 넘어짐 항목은 실패가 없고, 어느 항목이든 통과가 아닌 게 있음 (구역 밖·금지구역, 경계값 근처, GPS 부족, 보정 전 등) |
| 다시 세우기 | 넘어짐 항목(넘어짐, 좌우 기울기, 앞뒤 경사, 흔들림+경사) 중 실패가 있음 |

구역 밖은 넘어짐과 무관해서 확실히 밖이어도 사진으로 끝납니다. 대신 앱 첫 화면인 **주행 탭**이 달리는 동안 가장 가까운 주차구역을 지도에 강조해서, 세우기 전에 구역으로 가게 유도합니다.

NFC 바인딩(휴대폰이 그 킥보드 위에 있었다는 증거)은 웹 버전에서 빠져 있습니다. iPhone 브라우저가 Web NFC를 지원하지 않기 때문입니다.

## 배포 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다. 무료 계정은 **public** 저장소여야 Pages를 쓸 수 있습니다.
2. 이 폴더의 내용을 저장소 루트에 올립니다.
   ```bash
   git init && git add . && git commit -m "PM 주차 판정 실험 도구"
   git branch -M main
   git remote add origin https://github.com/<아이디>/<저장소>.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, 브랜치 `main`, 폴더 `/ (root)`로 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`로 접속합니다. 이 주소를 QR로 만들어 두면 현장에서 편합니다.

센서는 **HTTPS에서만** 켜집니다. 같은 와이파이에서 `http://192.168…`로 휴대폰 접속하면 모션·위치 권한이 거부됩니다.
PC에서 화면만 볼 때는 `python3 -m http.server`로 띄우고 `http://localhost:8000`으로 열면 됩니다(localhost는 예외로 허용).

## 처음 쓰는 순서

1. **센서 켜기** — iPhone은 모션 권한 창이 뜹니다. 허용하세요.
2. **센서 탭**에서 값이 맞게 움직이는지 봅니다. 화면을 위로 놓고 휴대폰 왼쪽을 내리면 휴대폰 좌우 값이 커져야 합니다.
3. **보정 탭** — 맨 위에서 휴대폰 위치를 고릅니다. 기본은 **핸들 거치대**입니다.
   - 거치대: 평평한 바닥에 킥보드를 스탠드로 세우고, 핸들을 똑바로 편 다음, 휴대폰을 화면이 나를 보게(한 변이 핸들과 나란하게) 꽂고 **기준 자세 저장**을 누릅니다. 이 한 번으로 휴대폰이 차체에 붙은 각도와 통과 구간(θ−4° ~ θ+10°)을 같이 잡습니다. 거치대 각도를 바꾸거나 다시 꽂으면 다시 하세요.
   - 발판(데크): 측정 자리에서 한 번, 같은 자리에서 180° 돌려 한 번 잰 뒤(카메라 범프 오프셋), 평지에서 기준 자세를 저장합니다.
   - 보정 전에는 다른 항목이 다 통과해도 결과가 사진으로 확인으로 나옵니다. 거치대 모드는 보정 전에 넘어짐 판정 자체를 하지 않습니다.
4. **구역 탭** — 허용/금지 구역을 지도에 그리거나, 현재 위치 기준 정사각형을 추가합니다. GeoJSON으로 가져오기·내보내기도 됩니다.
   데스크톱의 [geojson.io](https://geojson.io)에서 그린 뒤 가져와도 됩니다. 이때 `properties.kind`에 `allowed` 또는 `forbidden`을 넣으세요.
5. **주행 탭** — 주행 시작을 누르면(권한 허용) 내 위치를 따라가며 가장 가까운 허용구역의 테두리가 깜박이고 P 태그에 거리가 뜹니다. 손으로 지도를 움직이면 따라가기가 멈추고 내 위치로 버튼이 나옵니다. 도착하면 반납하기를 누릅니다.
6. **판정 탭** — 핸들을 똑바로 펴고, 도식 아래 미리보기 띠가 초록이 되는 자리를 고른 뒤, 휴대폰은 거치대에 꽂은 채로 측정 시작을 누르고 손을 뗍니다(발판 모드면 휴대폰을 화면이 위로, 윗변이 핸들 쪽을 향하게 데크에 올려 손을 뗍니다).
   - 결과별로 알림음이 다릅니다(통과는 올라가는 두 음, 사진 필요는 한 음, 다시 세우기는 내려가는 두 음).
   - 사진으로 확인이 나오면 결과 카드에서 바로 사진을 찍어 반납할 수 있습니다.
   - 12초 안에 멈추지 않고 계속 흔들리면, 마지막 3초 동안 흔들린 기울기 범위로 넘어질 위험을 판정합니다.
   - 결과를 본 뒤 휴대폰을 집어 들면 미리보기가 다시 움직여서, 다시 세울 자리를 고를 수 있습니다.
7. 결과가 나오면 **정답 라벨**(올바른 주차/잘못된 주차)을 남깁니다. 이게 있어야 잘못 통과시킨 비율을 셀 수 있습니다.
8. **기록 탭**에서 CSV나 JSON으로 내보냅니다. 기록은 브라우저 저장소(보통 5 MB)에만 있으니 실험이 끝날 때마다 내보내 두세요.

### iPhone 설정에서 확인할 것

- **정밀 위치**: 설정 → 개인정보 보호 및 보안 → 위치 서비스 → Safari 웹 사이트 → 정확한 위치 켬.
  꺼져 있으면 대략적 위치만 와서 결과가 늘 사진으로 확인이 됩니다.
- 모션 권한을 실수로 거부했다면 탭을 닫고 다시 열어 보세요. 그래도 안 되면 Safari 웹 사이트 데이터를 지우세요.

구역 탭의 **측정 기록을 지도에 표시**를 켜면 측정한 위치가 결과 색으로 찍힙니다. 어디서 잘못 세우는 일이 잦은지 보여줄 때 씁니다.

## 실험 제안

| 실험 | 방법 | 얻는 것 |
|---|---|---|
| 넘어짐 경계 | 경사판 각도를 바꿔가며 킥보드를 세우고 측정 + 실제로 넘어지는지 기록 | θmin, θmax, 필요 에너지 실측 |
| 넘기기 에너지 | 핸들 높이에서 저울로 밀어 넘어가는 힘 측정 | `넘기는 데 필요한 최소 에너지` 근거 |
| GPS 정확도 해석 | 위치를 아는 지점(측량점, 지도상 모서리)에 놓고 보고된 정확도 대비 실제 오차 분포 비교 | `정확도 해석`(drms, cep68, p95) 선택 근거 |
| 구역 크기 대 사진 생략률 | 크기가 다른 구역(5, 10, 20 m)에서 반복 측정 | 이 방식이 실제로 사진을 몇 % 없앨 수 있는지 |

## 판정 로직

판정 로직은 `js/core/`에 있고, 화면 코드와 섞이지 않은 순수 함수라서 `npm test`로 검증합니다.

- **정지** — 회전속도 < 0.03 rad/s, 선가속도 < 0.02 g 상태가 1.5초 이어진 끝 구간만 씁니다.
- **넘어짐** — 데크가 옆으로 45° 이상 누우면 기울기 판정 없이 넘어짐입니다. 135°를 넘으면(화면이 아래) 넘어짐이 아니라 놓은 자세 오류로 보고 사진으로 넘깁니다.
- **흔들림 + 경사** — 정지하지 못한 채 시간이 다 되면, 마지막 3초의 기울기(0.25초 이동평균)가 오간 범위가 통과 구간을 벗어나는지 봅니다. 평균 기울기가 구간 가장자리에 가까울수록(경사) 작은 흔들림에도 걸립니다.
- **자세** — 정지 구간 평균 중력을 차체 축(오른쪽 b, 앞 f, 똑바로 섰을 때 아래 d)에 투영해 킥보드 θ(스탠드 쪽 +)와 앞뒤 경사를 구합니다.
  발판은 휴대폰 축이 곧 차체 축이고 0°/180° 오프셋을 뺍니다. 거치대는 기준 자세의 중력 하나로 축을 잡습니다: 휴대폰 한 변이 핸들과 나란하고 평지라 앞뒤 경사가 0이라는 두 가정으로 f = b × g, d = f × b.
  θ는 스탠드 기울기 φ와 노면 횡경사 β의 합입니다. 넘어짐 판정에는 이 합 하나만 필요합니다.
- **넘어짐 모델** — 무게중심을 중력 방향으로 내린 점의 횡위치 $y_p = h\sin\theta/\cos(\theta-\varphi)$가 0과 d 사이에 있어야 서 있습니다.
  설정에서 실측값(h, d, φ, m)을 넣으면 θ 범위를 넘기는 데 드는 에너지 $mgh(1-\cos\theta)$와 스탠드 끝 여유로 다시 계산합니다.
- **위치** — 최근 10초 fix로 위치와 σ를 추정합니다. 연속 fix 오차는 서로 상관돼 있어서 평균으로 σ를 줄이지 않습니다.
  그다음 2D Gaussian을 격자 적분해 구역 안에 있을 확률을 구합니다. 구역 밖은 확률이 아니라 가장 가까운 허용구역까지의 거리(> 3σ)로 확정합니다.
  확률로 정하면 σ보다 작은 구역에서 정상 주차를 거부하기 때문입니다.
- **애매 구간** — 각도 임계값 ±0.7° 안이면 통과도 거부도 아닌 사진으로 넘깁니다.
- **결과** — `summarize()`가 정합니다. 넘어짐 항목(`FALL_CHECKS`)의 실패만 다시 세우기로 이어집니다.

기본 임계값은 전부 출발점입니다. 설정 탭에서 바꿀 수 있고, 측정 기록마다 그때의 설정이 함께 저장됩니다.

## 기록 형식

- CSV: 측정 1건이 1행입니다. 항목별 상태(`status.lean` 등)와 측정값(`lean.leanDeg`, `location.pAllowed` 등)이 열로 들어갑니다. 엑셀에서 한글이 깨지지 않게 BOM을 붙였습니다.
- JSON: 구역과 전체 기록이 들어갑니다. 기록마다 위치 fix 목록과 마지막 5초 원시 모션이 있습니다.
  원시 모션은 `[t, ax, ay, az, rx, ry, rz, userAccel]` 배열이고, 가속도는 브라우저가 준 m/s² 그대로입니다(부호 규약 미적용). `gravitySign`을 곱하고 9.80665로 나누면 아래 방향 중력(g)이 됩니다.

## 한계

- **바인딩 없음** — 바닥에 휴대폰만 기울여 놓아도 통과합니다. 실험 데이터 수집용으로만 보세요.
- **정확도 의미가 불확실** — 웹 명세는 accuracy를 95% 반경으로 정의하지만, 실제로는 OS 값을 그대로 넘기는 것으로 보입니다. 기본값은 가장 보수적인 drms입니다.
- **거치대는 핸들을 꺾으면 틀어짐** — 스템이 뒤로 누워 있어서 핸들을 20° 꺾으면 θ가 4~6° 다르게 읽힙니다(스템 기울기 10~15° 가정). 중력만으로는 조향과 기울기를 구분할 수 없어서, 측정 때 핸들을 펴라는 안내에 기댑니다.
- **흔들림 판정의 오탐** — 손에 든 채로 시간이 다 되면 손 움직임을 흔들림으로 볼 수 있습니다. 앞뒤로 30° 넘게 서 있으면 손에 든 것으로 보고 거르지만, 평평하게 들고 흔들면 못 거릅니다.
- **주행 지도는 안내용** — GPS 한 점을 그대로 써서 구역 안/밖 표시가 판정과 다를 수 있습니다. 판정은 반납 때 다시 합니다.
- **위치 위조 탐지 없음** — 판정 코드도 브라우저에 그대로 노출됩니다.
- **지도 타일** — OpenStreetMap 타일은 소량 실험용으로만 쓰세요. 항공사진(Esri)은 사용 조건을 확인한 뒤 쓰세요.
- **외부 의존** — 글꼴은 Google Fonts에서 받습니다. 오프라인이면 시스템 글꼴로 바뀝니다. Leaflet 1.9.4는 `vendor/`에 포함했습니다(BSD-2).
